# RAW corpus

This directory is reserved for exact corpus snapshots that have passed the project's provenance and reuse checks.

Do not place live API responses, manually copied text, transformed text, or unverified copyrighted material here.

Each accepted artifact must have a corresponding provenance manifest containing at least:

- CID
- source
- source URL/API endpoint
- edition
- language
- version
- retrieval timestamp in UTC
- SHA-256
- format
- license
- license evidence
- acquisition method

The current Zohar Hebrew source under consideration is not yet ingested because its reuse status requires verification. See `docs/corpus_policy.md` and `data/corpus_registry.json`.
